# M1d2: table-free service metadata, unchanged numerical parity

New offline amendment after M1d STOP_TABLE_STRUCTURE; freeze before row decoding.
Keep all M1c/M1d source, protocols, manifests, outcomes and original XML bytes.
The only new allowance is the actual ARI sibling RESOURCE with type=meta,
utype=adhoc:service and name=Datalink_GaiaDR3. The complete descriptor structure
must match: DESCRIPTION; char accessURL PARAM; inputParams GROUP containing one
sourceid long PARAM referring to the unique source_id FIELD ID. No TABLE, DATA,
FIELD, STREAM, RESOURCE or QUERY_STATUS may be hidden in this descriptor. All
full-document QUERY_STATUS values must be OK before removal. No URL is fetched.

This follows the table-free service-descriptor structure in
[IVOA DataLink 1.0 sections 4.1--4.2](https://www.ivoa.net/documents/DataLink/20150617/REC-DataLink-1.0-20150617.html).
A service descriptor is not an extra catalogue. Its name alone does not prove
standard DataLink compliance. We accept only this narrowly tested metadata
profile; unknown structures stop. Exact descriptor values and derived XML hash
are recorded, while the original hash remains authoritative.

Validate UTF-8/no DTD/entities/5 MB and the descriptor before removing that one
element in memory. Pass the remaining XML to the unchanged M1d decoder/validator
and compare to the unchanged ESA reader with M1c's exact 1290-ID/mask/unit and
numerical-tolerance requirements. Two numeric decoder agreement remains required.
No changed queries, thresholds, masks, IDs, physical interpretation or pixel work.
No network. No missing-field requests in this stage.

Reuse the frozen M1d execution harness in a freshly imported process-local module,
with only stage paths, script launch path, dependency collector and execute
function bound to M1d2. The original source and decoder functions stay unchanged.
New exclusive attempt/start/outcome receipts; same 60-second owner-context tree
deadline, <=1 GB observed peak-working-set acceptance and <=1 MB scientific JSON.
Replay is read-only and exact. Bind both original stages' hashes plus new
protocol/source/tests in the new manifest. Independent synthetic tests and review
must pass before freeze; no new lint exceptions. Failure is STOP_M1D2; success
is OFFLINE_CATALOG_PARITY_PASS with unknown_search_authorized=false.
