# CHIME periodicity: parked at the observing-window gate

Decision date: 2026-09-05. **PARKED — no unknown-source scan.**

A targeted recheck found no authenticated replacement for the missing
time-resolved observing/sensitivity product. The [official portal](https://www.chime-frb.ca/)
is being rebuilt and points users to permanent archives. The
[open-data documentation](https://chime-frb-open-data.github.io/), its
[release index](https://chime-frb-open-data.github.io/data-releases/) and
[exposure tutorial](https://chime-frb-open-data.github.io/exposure/) did not identify
a Catalog 2 operational-mask time series. The
[Catalog 2 methods](https://arxiv.org/html/2601.09399v1#S2.SS1) still describe
exposure integrated over the observing interval.

The September 2 authenticated HDF5 inspection remains decisive for the exact
file we possess: two one-dimensional `upper`/`lower` maps without a time axis.
The permanent archive's web directory produced an unpopulated dynamic table in
the read-only browser extraction; an attempted public VOSpace node URL returned
404. Therefore this refresh does **not** assert a newly exhaustive directory
inventory or that the collaboration lacks the data. It establishes that we
have not obtained the missing input. Searches used `CHIME Catalog 2 operational
data window` and followed the official portal/documentation references.

Restart only when a citable, authenticated product supplies operational and
nominal-sensitivity intervals for **2018-09-04 through 2023-09-15**, with enough
beam/transit metadata to compute time-resolved source exposure. Hash the exact
bytes, reproduce a known control with transit identifiers, and freeze a complete
new M1 protocol (null/clustering model, aliases, trials, global significance and
eligibility) before inspecting unknown-source peaks.

A future collaboration request is a possible route, but none was sent and no
continuing speculative scans or repeated service polling are warranted now.
