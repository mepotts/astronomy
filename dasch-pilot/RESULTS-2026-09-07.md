# Matched-colour validation and first exploratory screen

**Completed: instrumental holdout gate passed; 42-source screen found zero leads.**
No discovery or century-scale false-positive-rate claim.

The [strict specification](CALIBRATION-SPEC-2026-09-07.md) stopped on seven
Feige34 exposure-number conflicts before any held-out curves. Exact acquisition
is retained in [the original bundle](data/colour-20260907/responses.zip).
The [separate quarantine variant](CALIBRATION-JOIN-AMENDMENT-2026-09-07.md)
excludes conflicts and stops if they exceed 2% of any star's clean detections.
It does not guess corrected identities or relabel the strict run as passed.

Four of six fixed held-outs had unique APASS matches and useful colour-joined
coverage: P330-E, WD0713+584, G43-5 and G146-76. WD0046+051 and WD0148+467 failed
the unchanged unique-within-5-arcsecond match; no replacement or proper-motion
radius tuning. Across the four usable hold-outs there were **34 eligible
five-year windows**, no unmodified coherent two-series flags, and **16/16**
eligible signed one-magnitude injections recovered, spanning all four stars.
The original Feige66 1974 annual flag stays on record; the new five-year matcher
has a different estimand and does not retroactively clear that old alarm.

Matched baselines use the same series and continuous plate-representative APASS
colour term within 0.10, excluding the event window and one year on each side.
This is not full per-exposure/per-spatial-bin ASDF recalibration. Short SPSS
constancy runs do not prove century-long stability. Injections are conditional
on existing detections; they do not measure detection or plate-pipeline completeness.

## Actual unknown-source screen

The [new prospective search specification](SEARCH-SPEC-2026-09-07.md) capped
selection at 32 sources in each of two public control fields. Only 13 and 29
qualified, respectively: **42 selected, 42 usable, 361 eligible five-year
windows, zero local leads**. There were 44 successful requests and 59,883 clean
detections; a subsequent identity audit found zero repeated imaging keys within
source curves. This is a bounded exploratory null, not proof of no variables,
no undiscovered objects or a population incidence bound.

The [tracked summary](data/search-summary-20260907.json) is identity-free. Full
responses, request bodies and per-source outcomes stay in ignored
`data/search-20260907/`; no candidate-coordinate payload or submission was sent.
No outcome-dependent expansion of this sample was made. Broader selection would
be a new experiment with explicit multiplicity and candidate-validation costs.

## Reproduction

```powershell
python -m unittest discover -s dasch-pilot/tests -v
python dasch-pilot/scripts/colour_validation.py --replay --quarantine-conflicts
python dasch-pilot/scripts/exploratory_search.py --replay
```

34 tests and both cold replays passed locally. The public validation replay is
in CI; the private search replay requires the retained local responses and
fails closed without them. Eight new regression tests include colour-confounded
missing support, injection survival, strict-vs-quarantine behavior and capped
catalogue selection. The original pilots/results remain unchanged.
